# ChessYar Professional — شطر یار حرفه‌ای

برنامه تحلیل شطرنج با Flutter برای ویندوز ۱۰/۱۱ — رابط فارسی راست‌به‌چپ، تم تیره‌ی حرفه‌ای (سرمه‌ای/طلایی)، مهره‌های دقیقاً لیچسی (مجموعه cburnett).

این مخزن روی **GitHub Actions** بیلد می‌شود؛ یعنی **نیازی به نصب Flutter یا هر ابزار دیگری روی سیستم شما نیست.** هر بار که کد را push کنید، فایل نصبی `ChessYar-Setup.exe` به‌صورت خودکار ساخته می‌شود.

## وضعیت فعلی (نسخه 0.1.0)

| بخش | وضعیت |
|---|---|
| تحلیل بازی (تخته لیچسی + قوانین کامل + FEN/PGN) | فعال |
| تنظیمات (۶ تم تخته + صدا + درباره) | فعال |
| بازی‌های من، تمرین تاکتیک، کاوشگر گشایش، بانک اطلاعاتی، تحلیل موقعیت، آمار عملکرد | به‌زودی (طبق نقشه راه ۹ مرحله‌ای) |
| موتورهای UCI (Stockfish/Berserk/Viridithas) | در همین بیلد دانلود و کنار برنامه نصب می‌شوند؛ اتصال UCI در بیلد بعدی فعال می‌شود |

## چطور Setup.exe را بگیرم؟ (بدون نصب هیچ ابزاری)

### ۱) ساخت مخزن در گیت‌هاب
1. در github.com ثبت‌نام/ورود کنید.
2. دکمه سبز **New repository** → نام: `chessyar` → انتخاب **Public** یا **Private** (هر دو بیلد رایگان دارند) → **Create repository**.

### ۲) آپلود فایل‌ها
1. محتوای فایل `chessyar-github-upload.zip` را استخراج کنید.
2. در صفحه مخزن جدید، روی لینک **uploading an existing file** کلیک کنید.
3. وارد پوشه استخراج‌شده شوید، **همه‌ی فایل‌ها و پوشه‌ها را انتخاب کنید (Ctrl+A)** و آن‌ها را به صفحه آپلود بکشید.
   - مهم: خودِ پوشه را نکشید؛ محتویات داخلش را. پوشه‌ی مخفی `.github` باید حتماً آپلود شود.
4. پایین صفحه روی **Commit changes** بزنید و چند ثانیه صبر کنید.

### ۳) بیلد خودکار
1. تب **Actions** را باز کنید — بیلد «Build Windows Installer» به‌صورت خودکار شروع می‌شود.
2. حدود ۱۵ تا ۲۵ دقیقه طول می‌کشد (بیلدهای بعدی با کش سریع‌تر هستند).
3. بعد از تیک سبز، روی همان بیلد کلیک کنید و در پایین صفحه بخش **Artifacts** فایل **ChessYar-Setup** را دانلود کنید.

### ۴) نصب
1. فایل دانلودی یک zip است؛ داخل آن `ChessYar-Setup.exe` قرار دارد.
2. آن را اجرا کنید → Next → Install → Finish.
3. آیکون **ChessYar Professional** روی دسکتاپ و در منوی Start ظاهر می‌شود.

### نسخه رسمی (Release)
اگر در gith‌هاب یک تگ با الگوی `v1.0.0` بسازید (Releases → Draft a new release → Choose a tag)، همان بیلد به‌صورت خودکار یک Release با فایل Setup می‌سازد که لینک دانلود همیشگی دارد.

## اجرای بیلد دستی
تب Actions → «Build Windows Installer» → **Run workflow**.

## نکات فنی

- **بیلد:** Flutter 3.50.0 stable روی `windows-latest`؛ تست‌ها و analyze در هر بیلد اجرا می‌شوند و در صورت خطا بیلد fail می‌شود.
- **موتورها:** اسکریپت `scripts/fetch_engines.ps1` آخرین نسخه رسمی سه موتور را دانلود و کنار exe نصب می‌کند. اگر دانلود یکی ناموفق باشد، بیلد نمی‌شکند؛ فقط آن موتور در برنامه فهرست نمی‌شود.
- **قوانین شطرنج:** کتابخانه dartchess (همان که لیشس استفاده می‌کند) — شامل قلعه، آن‌پاسان، ارتقا، کیش/مات/پات.
- **مهره‌ها:** مجموعه cburnett اثر Colin M.L. Burnett (همان مهره‌های پیش‌فرض لیشس) — مجوزها در `ATTRIBUTION.md`.
- **فونت:** Vazirmatn (OFL).
- **بعدی:** اتصال UCI واقعی به موتورها، صداها، سپس بخش‌های بعدی طبق نقشه راه.
